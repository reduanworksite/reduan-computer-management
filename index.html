🗄️ Database — ১০টি Sheet, মোট ১২০টি Column

Spreadsheet: REDUAN_COMPUTER_MASTER_DATABASE · Drive Folder: REDUAN_COMPUTER_DATABASE · Spreadsheet খুলুন (২৬ নভেম্বর ২০২৬ যাচাই করা হয়েছে — ১০টি Sheet, ১২০টি Column, ৮টি Settings, ৫টি কোর্স)

Students ২৩টি কলাম Courses ১৫টি কলাম Batches ১৪টি কলাম Admissions ২১টি কলাম Payments ১২টি কলাম Expenses ৯টি কলাম AdminUsers ৯টি কলাম Notifications ৭টি কলাম Settings ৪টি কলাম ActivityLogs ৬টি কলাম
  • প্রতিটি Record-এর Unique ID (Student ID: RC-2026-0001, Application ID: APP-2026-0001, Payment ID: PAY-2026-0001)।
  • Delete-এর পরিবর্তে Soft Delete / Archive — ইতিহাস কখনো হারাবে না।
  • একই Transaction ID দিয়ে দ্বিতীয় পেমেন্ট বা আবেদন গ্রহণ করা হবে না।

⚙️ Backend — Code.gs, ৩৩টি Action

Google Apps Script backend (১,৩৩০ লাইন)। মূল Action গ্রুপগুলো:

  • Public: publicGetCourses, publicGetBatches, submitAdmission (Application ID তৈরি, Duplicate Transaction ID যাচাই), getSettingsPublic।
  • Auth: adminLogin (SHA-256 হ্যাশ যাচাই, ৮ ঘণ্টার টোকেন), verifyToken, adminLogout, changePassword।
  • Students ও Admissions: getStudents, searchStudents, createStudent, updateStudent, getAdmissions, approveAdmission (Student ID তৈরি), rejectAdmission।
  • Courses ও Batches: getCourses, createCourse, updateCourse, deleteCourse (Soft-Delete), getBatches, createBatch, updateBatch।
  • Payments ও Expenses: recordPayment (একই লেনদেনে Paid/Due/Status আপডেট), getPaymentHistory, getExpenses, createExpense।
  • Reports, Backup ও অন্যান্য: getDashboardStats, getReports, createBackup, getNotifications, markNotificationRead, getSettings, updateSettings।
  • সব লেখা LockService-এর ভেতরে — একাধিক অ্যাডমিন একসাথে কাজ করলেও Duplicate বা Conflicting ডেটা হবে না।

🖥️ Frontend — ২৬টি ফাইল

  • Public Website: Homepage (Hero, কোর্স, Why Choose Us, ভর্তি প্রক্রিয়া, যোগাযোগ), Course Listing, Course Details, Online Admission Form (সব ফিল্ড, বাংলাদেশি মোবাইল যাচাই, সাফল্যে Application ID দেখায়)।
  • Admin Dashboard — ১৪টি মেনু: Overview, Students, Admissions, Courses, Batches, Payments (রসিদ + প্রিন্ট), Due Management, Expense Management, Reports & Analytics (CSV ডাউনলোড), Notifications, Website Settings, Backup & Restore, Admin Settings, Logout।
  • Premium Blue & White ডিজাইন, Hind Siliguri বাংলা ফন্ট, Light & Dark Mode, মোবাইল রেসপন্সিভ।

সৎভাবে জানানো হচ্ছে

⚠️ ভুয়া ডেটা কোথাও নেই

  • Dashboard-এর সব সংখ্যা Google Sheets-এর বাস্তব ডেটা থেকে আসবে। Backend এখনো সংযুক্ত হয়নি বলে Dashboard-এ “Backend সংযুক্ত হয়নি” দেখায় — কোনো বানানো শিক্ষার্থী, টাকা বা ভর্তির সংখ্যা দেখানো হয় না।
  • কোর্সের ফি, মেয়াদ, মোট ক্লাস, শিক্ষকের নাম — এগুলো এখনো নির্ধারিত হয়নি বলে অনুমান করে বসানো হয়নি; ফি খালি থাকলে “ফি জানতে যোগাযোগ করুন” দেখায়। মালিক Dashboard থেকে বসাবেন।
  • bKash/Nagad পেমেন্ট নম্বর — এখনো জানানো হয়নি, তাই খালি রাখা হয়েছে; কোনো নম্বর অনুমান করে বসানো হয়নি।
  • Admin পাসওয়ার্ড — কোথাও লেখা নেই (Frontend বা Backend কোনো কোডেই নয়)। সেটআপের সময় মালিক নিজে পাসওয়ার্ড ঠিক করবেন; এটি SHA-256 Hash করে সংরক্ষণ করা হবে।
  • একাধিক Admin অ্যাকাউন্ট (listAdmins / createAdmin) — এখনো Backend-এ যোগ হয়নি; Phase 5-এ যোগ করা হবে। একজন Admin দিয়ে পুরো সিস্টেম চলবে।
  • Backend-এর Live পরীক্ষা (লগইন, ভর্তি সাবমিট, পেমেন্ট) এখনো হয়নি — কারণ Apps Script এখনো Deploy করা হয়নি। Deploy-এর পরেই আসল পরীক্ষা হবে।

মালিকের কাছ থেকে যা প্রয়োজন

⏳ ফোল্ডারে নেওয়ার অনুমোদন (ছোট ধাপ)

Spreadsheet তৈরি হয়ে গেছে, কিন্তু সেটিকে “REDUAN_COMPUTER_DATABASE” ফোল্ডারের ভেতরে নেওয়ার অনুমোদন কার্ডের মেয়াদ শেষ হয়ে গেছে। “আবার চেষ্টা করো” বললেই এই ধাপটি শেষ করা হবে — কার্ড এলে তখনই Approve করবেন। এছাড়া Phase 5-এ Apps Script Web App Deploy করার সময় আপনাকে নিজের ব্রাউজারে Google-এর অনুমোদন দিতে হবে। আপনার Google Password কখনো চাওয়া হবে না।

  • ঐচ্ছিক সিদ্ধান্ত (এখনই না জানালেও চলবে): কোর্সের ফি ও মেয়াদ, bKash/Nagad পেমেন্ট নম্বর, Admin Username (ডিফল্ট: admin)। এগুলো পরে Dashboard থেকেও বসানো যাবে।
  • Apps Script Deploy: Phase 5-এ Web App Deploy করার সময় আপনাকে নিজের ব্রাউজারে Google-এর অনুমোদন দিতে হবে।
